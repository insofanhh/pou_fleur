# Fleurious brand assets

- `fleurious-mark.svg`: editable botanical F: a stem, flowering upper branch and leaf-shaped middle arm, black on transparent.
- `fleurious-logo.svg`: horizontal logo lockup.
- The website retains its original text wordmark. The botanical mark is used for favicon/PWA and the collapsed dashboard sidebar.
- Run `node scripts/generate-brand-assets.mjs` after editing the mark to rebuild favicon, Apple and PWA icons.

`google-g.svg` retains the geometry, colors and gradient from Google's approved Android + Web light SVG asset (icon crop only). Source: https://developers.google.com/identity/branding-guidelines and https://developers.google.com/static/identity/images/signin-assets.zip . Google branding belongs to Google; do not recolor this asset.
